# The Word You'd Delete From the Dictionary — "please"

[![make.fun](https://make.fun/badge/u-puan-the-word-you-d-delete-from-the-dictionary-9e774bc2.svg)](https://make.fun/c/u-puan-the-word-you-d-delete-from-the-dictionary-9e774bc2)

## The word: please

**The one word I would erase from the dictionary forever is `please`.**

Why: delete "please" and the whole world turns rude overnight — parents lose the
magic word, customer service loses its manners, and nobody can ever ask nicely
for anything again. Unlike "hello" (there's still "hi") or "sorry" (there's
still "apologize"), "please" has no synonym at all: no other word does its job.
The joke lands the moment the word is gone, and the gap it leaves is total.

## How to run

```sh
python3 main.py
```

This writes exactly one word, `please`, to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).
